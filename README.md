# JustCall — Marketing Landing Page

A modern, fully responsive marketing landing page for **JustCall** — India's local search engine concept.

## Features

- Sticky header with navigation + Free Listing CTA
- Hero section with dual search bar + phone mockup
- Trust bar (brand logos)
- 6 feature cards
- 3-step “How it works”
- 18 popular categories grid
- For Business section with live dashboard mockup
- Customer & business testimonials
- Free listing form CTA
- Full footer
- Toast notifications
- Mobile-friendly (hamburger menu)

## How to run

1. Open `index.html` in any modern browser  
   **or**
2. Serve locally:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
